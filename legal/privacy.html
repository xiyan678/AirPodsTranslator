隐私政策

耳译 · 更新日期：2026 年 10 月 29 日

东莞市夕颜网络科技有限公司尊重你的隐私。以下说明当前版本如何处理语音、文字、图片、对话记录和订阅信息。

1. 我们处理的信息

麦克风语音用于实时识别和翻译；你选择的图片或拍摄的照片用于文字识别；输入的文字用于翻译；语言偏好、语速、术语和免费额度保存在设备上。你主动保存的对话会写入 App 的本地存储。

2. 本地处理与网络下载

语音转写、图片文字识别、已安装语言包的翻译和对话记录处理在设备上完成。首次使用语音模型时，App 会从模型提供方下载模型文件；离线翻译语言包由苹果系统下载和管理。相关服务可能处理下载请求所需的网络信息，例如 IP 地址。打开实时总结或手动刷新时，对话原文和译文将通过 HTTPS 发送给耳译总结接口，并由阿里云百炼 Qwen 生成总结。接口不主动保存对话正文，也不接收原始音频或图片。若你在设置中开启自己的模型 API 并填写密钥，总结文字会直接发送给你选择的模型服务，不经过默认总结接口。自定义 API Key 保存在本机钥匙串，可在设置中清空；第三方服务的数据处理规则以对应平台政策为准。关闭实时总结刷新或关闭总结面板会停止后续自动请求。

3. 苹果服务与订阅

购买、续订、恢复购买和订阅管理由 Apple StoreKit 与 App Store 处理。App 读取苹果验证过的订阅资格，用于解锁 Pro 功能；我们不在 App 内取得银行卡完整信息。苹果的翻译服务可能收集 API 使用及性能信息，具体以苹果的隐私政策为准。

4. 设备间传递与主动分享

如果你使用配对的 Apple Watch，App 会将当前运行状态和最新译文发送到手表。只有在你主动点按分享时，所选内容才会交给系统分享面板及你选择的目标 App。

5. 保存、删除与权限

对话记录默认不自动保存；你可以在设置中开启自动保存，也可以手动保存。已保存的对话可在历史页删除，术语可在设置中删除。卸载 App 会移除其本地数据；系统语言包由 iOS 管理。你可以在 iOS 设置中关闭麦克风、相机或照片访问权限，关闭后相应功能无法使用。

6. 联系与政策更新

如对数据处理有疑问，可通过 抖音联系作者。若将来加入云端翻译、账号、分析或广告等功能，我们会先更新本政策，并按要求更新 App Store 隐私信息。
